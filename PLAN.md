## Contract ownership

No module owns private copies of shared state shapes. Add the initial definitions under src/lib/contracts and have adapters import them. The simulator/evaluator may read hidden truth; mission planning, motion control and harness code receive observations and estimates only. Every actuation path goes through the harness.
